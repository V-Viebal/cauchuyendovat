# Monos Platform

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/c4ebbc58-4e6f-410f-9475-c202007f64fd

## Chạy local

**Prerequisites:**  Node.js


1. Cài dependencies: `npm install`
2. Chạy development: `npm run dev`
3. Mở [http://localhost:3020](http://localhost:3020)

## Build

- Build production: `npm run build`
- Output mới: `dist-monos/`
- Preview production: `npm run preview` tại [http://localhost:3011](http://localhost:3011)
